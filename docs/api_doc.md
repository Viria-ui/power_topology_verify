# CP-202606 面向新型电力系统的配电网图模拓扑智能识别与修正研究榜题答疑

## 核心准则

1. 现有数据是模拟的真实数据，真实数据存在一些质量问题。
2. 拓扑分析以结构化模型数据（CSV/SQL表）为主，SVG图形用于辅助验证与可视化。
3. 无遥信记录的开关默认合位。图形分位可自行判断是否使用。
4. 站房TYPE = null 不处理。PWROOM找不到的不管。
5. 互感器缺失不影响。

## 需修正数据

1. 配网遥测/信重复记录按 TRAN_ID + DATA_DATE 去重。
2. 设备类型码1312 应为 1321。
