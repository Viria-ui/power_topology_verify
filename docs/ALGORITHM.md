# 电力拓扑与图模校验 · 核心算法说明

> 本文档说明本项目四大校验任务与 SVG 美化/生成的核心算法、数据口径与已知设计取舍，
> 供评审与维护参考。数据均为全量实测口径（2026-09-07 修复后基线）。

## 1. 任务一：拓扑校验（四类校验 + 评分）

### 1.1 拓扑结构完整性（悬空/断点/联络/合环）

- **电源判定（S1 修复）**：`TopologyBuilder._is_source_type` 只认
  `1701`（主网站房）与 `SOURCE_TYPES` 集合、变电站/主变等名称关键字；
  **`1702`（馈线段XX，实测 17643 台）不再判定为电源**。修复前整条配网馈线
  被注入 is_source（17643 台，34.8%），孤岛/悬空/合环判定全部失真；
  修复后 is_source=175（全部为真实主网电源及主网出线开关）。
- **主配对接（S2 修复）**：配网端子 CN（负数，35735 个）与主网端子 CN
  （正数，709 个）存在 **147 个重叠 CN**；对每个重叠 CN 建立主网端子↔配网
  端子物理连接边（实测 324 条跨边，覆盖 146 个 CN），使配网馈线通过真实
  物理连接接入电源，替代"整条馈线注入电源"的错误做法。
- **断点检测**：`feeder_topology_analysis.analyze_breakpoints`（主用版本在
  397 行；166 行为兼容入口，保留以防外部引用）。基于端子连通性对开关设备
  两端分别做连通性判定，输出 P1-P7 断点。
- **联络/合环（S3 修复）**：`detect_cycle_based_loop` 用 `nx.cycle_basis`
  找环，环内含联络开关候选（跨≥2 馈线+开关类型+名称/类型豁免）时，按
  **遥信实测状态三分类**：
  - 分位（OPEN/0/分位）→ `合规联络(分位)`，EXEMPT 不扣分
  - 合位（CLOSE/1/合位）且状态来源非默认推演 → `非计划合环`
  - 未知/默认推演 → `疑似联络环(需复核)`
  - 实测：联络/合环 229 = 合规联络 24 + 疑似 118 + 非计划合环 87。

### 1.2 图模一致性（SVG ↔ 数据库）

- SVG 图元 ID 与 SQL 主键集合差集比对：图有模无 / 模有图无。
- 电压等级（S6 修复）：SVG 节点无电压属性时，从 **SVG 文件名**
  （`10kVLINE003.svg`）推断电压等级，不再硬编码 "10kV"。
- 断点/联络的 SVG 局部图校验与全库拓扑校验双通道互证。

### 1.3 电气逻辑（E01-E07，M3 修复后阈值）

| 规则 | 判定条件（修复后） |
|---|---|
| E01 | 分位且 I>1.0A |
| E02 | 合位且 I<0.05A 且 U>0.8Un（Un=5.7735kV 相电压基准） |
| E03 | 合位且 I≈0∧U≈0∧P≈0∧Q≈0 |
| E04 | (Imax-Imin)/Iavg>20% |
| E05 | 合位且 I>0.5A∧U>0.8Un∧偏差>15% |
| E06 | 分位且 \|P\|>0.1kW 或 \|Q\|>0.1kvar |
| E07 | 合位且 I<0.05A∧\|P\|>5.0kW |

实测：电气缺陷 3272（E01=119/E02=440/E03=1287/E04=980/E05=323/E06=56/E07=67）。
遥信状态统一大写口径（M5 修复）：OPEN/CLOSE/0/1/分位/合位 跨模块一致。

### 1.4 主配网接口校验

- 189 条配网馈线通过 LINE_NAME↔ZWLINEEND 映射对接主网出线，实测 184 通过、
  5 失败（真实数据缺陷：START_ST_ID 为空）。

### 1.5 质量评分（S7 修复，规范书 v1.1 + 电气逻辑校验规则 v1.0 第五章）

```text
Model_Score = 100 - Σ(W_i × C_i)
W_i: 拓扑完整性5 / 图模一致性3 / 电气逻辑2 / 接口规范性4
C_i: 该维度缺陷处数（不按置信度打折，无缺陷率惩罚）
单维度扣分封顶: 30/25/20/25
score_after = 移除已修复缺陷处数后重算
```

## 2. 任务二：SVG 美化与生成

- **美化**（`svg_io/svg_beautifier.py`）：解析原 SVG → 设备/连接图元提取 →
  力导向/网格布局 → 断点修复 → 连通分量合并 → 输出美化 SVG。
  布局与 HTML 渲染框架为**已验收固定版本**，后续修复一律在输入数据层完成，
  不改美化算法本身。
- **生成**（`svg_io/svg_auto_generator.py`）：单线图 / 联络图 / 电源追溯图 /
  auto_index，基于全库拓扑遍历渲染。

## 3. 数据与已知设计取舍

- **组合开关 1720（8871 台）**：PWTERMINAL 端子为 0（COMPOSITESWITCH 列全为
  'null' 脏字符串——真实数据缺陷），按悬空暴露（悬空 9379 + 单端 186），
  并在报告中如实呈现而非静默豁免。
- **三套拓扑分析算法并存**（M8 标注）：`topology_validator.TopoDbValidator`
  为主用；`feeder_topology_analysis` 与旧版重复入口保留并标注兼容用途，
  便于横向比对，不删除。
- **SQL 解析**（M9 修复）：括号深度感知解析器，支持值内逗号、单条 INSERT
  多元组、多行 VALUES、单引号转义；11 张表全量比对与旧解析器一致
  （equip 50744 行等无丢行）。
- **连通分量**：各调用点对不同图实例计算，无共享缓存对象，故不引入缓存
  （避免缓存失效引入新 bug）。

## 4. 输出文件
