## 1. 项目背景

### 1.1 问题来源

在电力系统中，配电网（10kV）负责将电能从高压主网（110kV）配送到用户端。由于历史原因和长期运行维护，配电网数据常存在以下问题：

- **图模不一致**：CAD绘制的SVG单线图与数据库记录存在差异
- **拓扑错误**：设备连接关系缺失、错误或冗余
- **数据孤岛**：遥测数据与拓扑模型无法关联
- **维护滞后**：设备退役后未及时更新图纸和数据库

### 1.2 解决方案

本系统通过**图模一致性比对**技术，自动发现SVG图纸与数据库之间的差异，结合**电气逻辑校验**和**物理约束检查**，输出：

- 可量化的质量评分
- 定位到设备级别的缺陷清单
- 可直接执行的SQL修复脚本
- 支持回滚的逆向操作

## 2. 业务背景

### 2.1 电压等级体系

```
                    ┌─────────────┐
                    │  主网 110kV │
                    └──────┬──────┘
                           │ 变电站降压
                           ▼
                    ┌─────────────┐
                    │  配网 10kV  │ ◄── 本系统主要处理对象
                    └──────┬──────┘
                           │ 配电变压器降压
                           ▼
                    ┌─────────────┐
                    │   用户 0.4kV│
                    └─────────────┘
```

### 2.2 关键概念

| 术语 | 解释 |
|------|------|
| **主网** | 110kV及以上电压等级，负责电能传输 |
| **配网** | 10kV电压等级，负责电能配送到用户 |
| **馈线** | 从变电站母线引出的配电线路 |
| **联络开关** | 连接两条馈线的开关，用于转供负荷 |
| **断点** | 线路上的开关断开点，可能导致供电中断 |
| **合环** | 两条馈线同时合位，形成环形供电 |
| **SVG单线图** | CAD绘制的配电线路接线图 |
| **图模一致性** | SVG图纸与数据库拓扑模型的一致性 |

## 5. 核心模块

### 5.1 图模型 (core/graph_model.py)

| 类名 | 作用 |
|------|------|
| `Device` | 设备实体（ID、名称、类型、电压等级、是否电源） |
| `ConnectPoint` | 连接端子（端子ID、所属设备ID、所属馈线） |
| `TopoEdge` | 拓扑边（线路ID、起点端子、终点端子） |
| `AbnormalItem` | 异常项（异常类型、规则编码、风险等级） |
| `BreakpointItem` | 断点项（断点位置、优先级） |
| `TieLoopItem` | 联络/合环项（联络开关位置、合环判定） |
| `TopologyGraph` | 拓扑图（封装NetworkX图） |

### 5.2 拓扑构建器 (core/topology_builder.py)

```
1. 电压等级拆分
   ├─ 主网设备 (电压=110kV)
   └─ 配网设备 (电压=10kV)

2. 设备节点添加
   └─ 识别电源设备 (变压器、配变)

3. 端子点添加
   └─ 建立设备-端子关联

4. 拓扑建边
   ├─ 端子-端子连通 (CONNECT_NODE)
   └─ 设备内部通路补齐

5. 遥信预处理
   ├─ 开关状态采集
   └─ 10秒防抖处理
```

### 5.3 拓扑校验器 (core/topology_validator.py)

| 规则 | 名称 | 说明 |
|------|------|------|
| R001 | 端子悬空 | 开关类设备单端悬空 |
| R002 | 孤岛设备 | 连通分量内无电源 |
| R003 | 馈线断点 | 同馈线设备分布在多个连通分量 |
| R_TIE | 联络开关 | 分位状态、两侧可连通不同馈线 |
| R_LOOP | 合环检测 | 非计划合环识别 |

### 5.4 电气逻辑校验 (core/telemetry_evaluator.py)

| 规则 | 名称 | 物理含义 |
|------|------|----------|
| E01 | 分位有电流 | 开关分位时不应有电流流过 |
| E02 | 合位失流 | 开关合位但电流为零，可能是虚接 |
| E03 | 合位失压 | 合位开关但电压为零 |
| E04 | 电流不平衡 | 三相电流不平衡度过大 |
| E05 | 功率不匹配 | 功率与电流电压不匹配 |
| E06 | 分位有功率 | 分位开关不应有功率流 |
| E07 | 小电流大功率 | 功率很大但电流很小 |

### 5.5 评分引擎 (core/score_engine.py)

```
┌─────────────────────────────────────────────────────┐
│                    图模质量评分 (满分100)             │
├───────────────┬───────────┬───────────┬──────────────┤
│   拓扑完整性   │  图模一致性 │  电气逻辑  │     接口规范性 │
│     (权重5)    │   (权重3)  │  (权重2)  │      (权重4)  │
├───────────────┼───────────┼───────────┼──────────────┤
│  扣分上限30   │  扣分上限25 │  扣分上限20│     扣分上限25│
└───────────────┴───────────┴───────────┴──────────────┘
```

## 附录：常见问题

### Q1: 如何调整评分权重？
**方法**：修改 `config/constants.py` 中的 `SCORE_WEIGHTS`

### Q2: 如何添加新的校验规则？
**方法**：在 `core/topology_validator.py` 中添加新的校验方法

### Q3: 支持哪些SVG格式？
**支持**：标准SVG 1.1格式，包含 `<metadata>` 标签的图元

### Q4: 测试脚本输出乱码？
**原因**：Windows命令行编码问题，不影响实际输出文件
